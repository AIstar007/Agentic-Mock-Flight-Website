# Hosted deployment (free-first Render + MongoDB Atlas)

This deployment serves the React frontend and FastAPI backend on Render. **For a no-cost starter setup, MongoDB Atlas Free is used for sessions, redacted audit events, and LangGraph checkpoints. Redis is optional.** Neo4j Aura is optional because the versioned local JSON rule catalog remains the deterministic fallback. Navitaire and Timatic remain mock-only.

## Important limits

- You create the provider accounts/resources and set secrets in Render. No credentials are generated by this repository.
- Render Free web services spin down after idle time and can take about a minute to wake up. Free hosting is for demos, not production availability.
- MongoDB Atlas Free has storage/connection limits and is suitable only for small development projects here. Do not store real passenger data in this POC.
- **Do not use Redis Cloud Free over a public connection from Render.** Redis documents that TLS is not available for its Free Essentials tier. The LangGraph Redis checkpointer also expects compatible RedisJSON and RediSearch commands. This project now supports a MongoDB-backed LangGraph checkpointer so Redis is not required for the free profile.
- Neo4j AuraDB Free can pause after inactivity and has no managed backups. It is optional; local JSON rules are the fallback.
- This is a mock-only POC, not an Emirates product or a production airline application.

## A. Create MongoDB Atlas Free (required)

1. Open https://cloud.mongodb.com/ and create a project.
2. Create an Atlas Free (`M0`) cluster in a region near the backend, if available.
3. Under **Database Access**, create a dedicated database user with a strong generated password. This is separate from your Atlas website login.
4. Under **Network Access**, allowlist the Render backend's outbound IP ranges. Find them in the Render service dashboard under **Connect → Outbound**. Avoid `0.0.0.0/0` as a convenience workaround.
5. In **Connect → Drivers**, select Python and copy the SRV connection string. Replace `<username>` and `<password>` with your database user's values; URL-encode special characters in the password.
6. The application creates its own collections for sessions, audit events and LangGraph checkpoints in `emirates_checkin_demo`. Do not create a publicly exposed database.

## B. Optional Redis Cloud (not needed for free-hosted mode)

Redis may be added later for caching or shared session acceleration. For a public hosted connection, use a TLS-enabled plan and verify RedisJSON + RediSearch-compatible commands for the pinned LangGraph Redis checkpointer. Redis Cloud Free Essentials has no TLS, so leave `REDIS_URL` and `LANGGRAPH_REDIS_URL` blank for the recommended free setup.

### 3. Neo4j Aura (optional)

1. Open https://console.neo4j.io/ and create an AuraDB instance.
2. Save the instance URI, username and generated password from the creation details.
3. Use its secure `neo4j+s://...` URI for `NEO4J_URI`.
4. AuraDB Free can pause after inactivity. The POC's rule catalogue in `backend/data/rules_catalog.json` remains the deterministic fallback. Do not make production decisions based on this illustrative graph.

## B. Publish this repository to GitHub

1. Extract this project archive into a normal folder.
2. Create a **private** GitHub repository for the POC (recommended even though only synthetic data is included).
3. Push the project files, including `render.yaml`. Do not upload any `.env` file or real provider credentials.
4. Ensure `render.yaml` is at the repository root.

## C. Deploy the Blueprint on Render

1. Open https://dashboard.render.com/ and connect the GitHub repository.
2. Choose **New > Blueprint**, select the repository, and let Render read `render.yaml`.
3. Render creates `emirates-checkin-api` and `emirates-checkin-demo`.
4. In the API service's Environment settings, set `MONGODB_URI` to the Atlas SRV connection string. `REDIS_URL` and `LANGGRAPH_REDIS_URL` remain blank for the free-hosted profile. Neo4j is optional; if you create Aura, add `NEO4J_URI`, `NEO4J_USERNAME=neo4j`, and `NEO4J_PASSWORD`.
5. The Blueprint sets `REQUIRE_PERSISTENT_STORAGE=true`; the API will not start unless MongoDB is configured and reachable. MongoDB stores sessions, redacted audit events and graph checkpoints so it does not silently fall back to in-memory state.
6. Confirm the frontend URL matches `https://emirates-checkin-demo.onrender.com`. If Render assigned a different URL, update `FRONTEND_ORIGIN` on the API service to that exact origin and redeploy the API.
7. Confirm the frontend build receives `VITE_API_BASE_URL` from the backend's `RENDER_EXTERNAL_URL`. If you rename the API service or move to a custom domain, redeploy the frontend after updating its environment variable.

## D. Smoke test after deployment

1. Open `https://<your-frontend>.onrender.com`.
2. Open `https://<your-backend>.onrender.com/api/v1/health`.
3. Confirm the response says `mode: MOCK_ONLY`, both providers are `mock`, and MongoDB session/audit persistence is configured. Redis can remain unconfigured.
4. Test synthetic PNR `EM8K2Q` / surname `THOMAS`, validate mock documents, pick seats, confirm mock ancillaries, and complete the mock check-in.
5. Test an expired passport and uncertain visa case; each must be blocked/escalated. Confirm no boarding pass appears while eligibility is unresolved.
6. Restart/redeploy the API and confirm sessions and graph checkpoints persist in MongoDB. Check MongoDB for redacted audit events only. Do not test with real PNRs or travel documents.

## E. Hosted environment variable meanings

| Variable | Required? | Value |
|---|---|---|
| `REDIS_URL` | No for the free-hosted profile | Leave blank; Redis Cloud Free does not support TLS |
| `LANGGRAPH_REDIS_URL` | No | Leave blank; the app uses the MongoDB checkpointer when Redis is not configured |
| `MONGODB_URI` | Yes | Atlas connection string |
| `MONGODB_DATABASE` | Yes | `emirates_checkin_demo` |
| `NEO4J_URI` | Optional | Aura secure URI (`neo4j+s://...`) |
| `NEO4J_USERNAME` | Optional | Usually `neo4j` for a new Aura instance |
| `NEO4J_PASSWORD` | Optional | Aura-generated password |
| `NEO4J_REQUIRED` | No; defaults false | Set true only if startup must fail without Neo4j |
| `REQUIRE_PERSISTENT_STORAGE` | true on Render Blueprint | Refuses memory-only sessions/audit/checkpoints when hosted |

Never put these values in Git, frontend environment variables prefixed by `VITE_`, screenshots, public issues or logs.
